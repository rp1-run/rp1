# rp1-eval-project

A minimal Bun project for testing rp1 agent evaluations.

## Scripts

- `bun run dev` - Run the main entry point
- `bun test` - Run tests
- `bun run lint` - Run linter
- `bun run format` - Run formatter

## Structure

```
src/
  index.ts    - Main entry point
  utils.ts    - Utility functions
```
