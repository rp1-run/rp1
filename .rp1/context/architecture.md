## Architectural Layers

| Layer | Purpose | Key Components |
|-------|---------|----------------|
| Interface (Skills) | User-facing entry points via slash commands | `plugins/*/skills/*/SKILL.md` |
| Agent Layer | Autonomous constitutional agents for single-pass execution | `plugins/*/agents/*.md` |
| CLI Core | Commander-based CLI with agent-tools registry and build pipeline | `cli/src/main.ts`, `cli/src/commands/`, `cli/src/agent-tools/` |
| Web UI | React/Vite/Tailwind real-time dashboard with WebSocket on port 7710 | `cli/web-ui/src/` |
| Data Layer | SQLite work status tracking with WAL mode, run isolation, TTL expiry | `cli/src/agent-tools/work/`, `~/.rp1/status.db` |
| Knowledge Layer | Persistent codebase documentation generated by KB agents | `.rp1/context/*.md`, `.rp1/context/state.json` |
| Build/Release | CI/CD, binary compilation, asset bundling, multi-channel distribution | `.github/workflows/`, `.goreleaser.yml`, `scripts/` |
| Evaluation | Promptfoo evals with content-addressable attestation | `evals/src/` |
| Shared Packages | Reusable internal libraries | `packages/catppuccin-mermaid/`, `cli/shared/` |

## Architectural Patterns

- **Plugin Architecture**: Three plugins (base, dev, utils) with `.claude-plugin` manifests; dev depends on base
- **Skill-Agent Delegation**: Skills are user-facing slash commands that delegate execution to autonomous markdown-defined agents
- **Map-Reduce Workflows**: Complex tasks split into parallel agent invocations with results merged by orchestrator
- **Builder-Reviewer Loop**: Builder agent produces work, reviewer validates with single-retry on failure
- **Constitutional Prompting**: Agents are declarative markdown specs constraining AI behavior through structural rules
- **Multi-Platform Distribution**: Single codebase generates platform-specific artifacts for Claude Code, OpenCode, and Codex
- **Single-File Executable**: GoReleaser + `bun --compile` produces standalone binaries with embedded web-ui and artifacts

### Release Pipeline
1. Conventional commits merged to main
2. Release-Please maintains rolling release PR with changelog
3. Merging release PR creates git tag
4. GoReleaser triggered: generates asset bundle, compiles 5 platform binaries
5. OpenCode artifacts built and uploaded to GitHub release
6. Cloudflare Pages deployment for docs
7. Lighthouse CI audits deployed docs site

| OpenCode | Secondary platform via tarball artifacts | Platform integration |
| Codex CLI | Third platform target (min_version 0.110.0, uses AGENTS.md) | Platform integration |
| Lighthouse CI | Performance/accessibility auditing for docs site | Quality assurance |

## Deployment Architecture

- **Distribution**: Multi-channel (Claude Code marketplace, OpenCode tarballs, GoReleaser binaries, Homebrew, Scoop, npm)
- **Target Platforms**: darwin-arm64, darwin-x64, linux-arm64, linux-x64, windows-x64
- **Installer**: `curl -fsSL https://rp1.run/install.sh | sh`
- **Docs**: Cloudflare Pages at rp1.run (MkDocs Material)
- **Current Version**: 0.5.1
